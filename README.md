# Shah Abdul Latif University Website

A simple and modern responsive university website for **Shah Abdul Latif University, Khairpur**, created using **HTML, CSS, and JavaScript**.

## 📌 Project Overview

This project is a single-page university website designed with a modern and simple user interface. It includes university information, departments, contact details, personalities carousel, login and registration pages.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern 2026-style UI
- 3D-style cards and hover effects
- Animated university logo and name on page loading
- 5-second intro/loading animation
- Smooth scrolling navigation
- Home section with background image
- About University section
- Departments and Institutes table
- University personalities image carousel
- Contact information
- Login page
- Registration page
- Responsive mobile navigation menu
- Interactive buttons
- Automatic image carousel
- Footer with quick links and copyright information

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Animations
- Flexbox
- CSS Grid
- Responsive Media Queries

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder.
3. Make sure the `images` folder contains all required images.
4. Open `index.html` in a web browser.

For a better development experience, you can use **Visual Studio Code** with the **Live Server** extension.

## 🖼️ Images

The website uses images for:

- University logo
- University/campus background
- University personalities

Place all images inside the `images` folder and use the same file names as shown in the project structure.

## 📱 Responsive Design

The website is designed to work on:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet

The navigation menu changes to a mobile menu on smaller screens.

## 📄 Main Pages

### Home

Contains:

- University welcome message
- Background image
- Introduction
- Action buttons

### About

Contains information about Shah Abdul Latif University with an image and description.

### Departments

Displays university departments and institutes in a responsive table.

### Personalities

Contains an automatic image carousel showing notable personalities.

### Contact

Contains:

- University location
- Email addresses
- Phone numbers
- Email button

### Login

A simple login form for users.

### Registration

A simple registration form for new users.

## 🎨 Design

The website uses:

- Green and dark-blue color combination
- Rounded cards
- Shadows
- Glass-style header
- Hover animations
- Smooth transitions
- Simple 3D effects

## ⚠️ Note

This is a **front-end project**. The Login and Registration forms currently do not have a backend or database.

To make authentication functional, a backend such as **Node.js/Express, PHP/MySQL, or another server-side technology** would be required.
